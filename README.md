# MoodMap

Ideia de um mapa social do clima de cada lugar: as pessoas dizem como está o ambiente e todas veem o resultado no mapa.

Estudo · iOS 26 · 2025

Hoje o repositório tem só o esqueleto do projeto SwiftUI, com a tela "Hello, world!" que o Xcode gera. O protótipo funcional do mesmo tema está em [Prototipo-MapKit](https://github.com/cauecarneiro/Prototipo-MapKit).

## A ideia
- Mapa com MapKit, onde cada pessoa avalia o ambiente do lugar (animado, tedioso, tranquilo e outros climas).
- Sincronização entre usuários por CloudKit.
- IA no aparelho (Foundation Models) para ler o tom das mensagens.
- Aviso aos outros usuários por notificação push.

Nada disso está implementado neste repositório. A lista acima vem do About original.

## Meu papel
O esqueleto do projeto foi enviado por Breno Marques (2 dos 3 commits). O terceiro, o commit inicial do repositório, é meu. Não há mais histórico.

## Tecnologias
Swift e SwiftUI. MapKit, CloudKit e Foundation Models são os frameworks planejados.

## Como rodar
1. Abra `MoodMap/MoodMap.xcodeproj` no Xcode e rode num simulador com iOS 26 ou mais novo.
2. A tela mostra só um texto de exemplo.
